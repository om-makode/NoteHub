# NoteHub

**NoteHub** is a centralized platform for students to **upload, retrieve, and share academic notes**. It provides a secure and organized way to access study materials.

---
## Features
- Upload and categorize notes by subject
- Secure user registration and login
- Admin review system for note approval
- Edit profile functionality
- Centralized storage for easy access
