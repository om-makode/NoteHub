# NoteHub
Created to upload, retrieve, and share academic notes, serving as a centralized storage platform for  students.

# Register Page
Users can create an account on the website.

Login Page
Users can securely access their accounts.


![image alt](https://github.com/om-makode/NoteHub/blob/6a8d33613f61acc6b12b6ef7b678e525a599b84a/images/Screenshot%202025-01-13%20225309.png)


User Dashboard

Displays notes uploaded by various users.

![image alt](https://github.com/om-makode/NoteHub/blob/6a8d33613f61acc6b12b6ef7b678e525a599b84a/images/user%20dashboard.png)

Upload Notes
Users can upload notes categorized by subject.

![image alt](https://github.com/om-makode/NoteHub/blob/6a8d33613f61acc6b12b6ef7b678e525a599b84a/images/Screenshot%202025-01-13%20222821.png)


Edit Profile
Users can update their profile, including profile image, name, email, bio, and password.

![image alt](https://github.com/om-makode/NoteHub/blob/6a8d33613f61acc6b12b6ef7b678e525a599b84a/images/Screenshot%202025-01-13%20222404.png)


After uploading, the request is sent to the admin for review, who can approve or delete the notes.

![image alt](https://github.com/om-makode/NoteHub/blob/6a8d33613f61acc6b12b6ef7b678e525a599b84a/images/2222.png)


![image alt](https://github.com/om-makode/NoteHub/blob/6a8d33613f61acc6b12b6ef7b678e525a599b84a/images/333.png)

![image alt](https://github.com/om-makode/NoteHub/blob/6a8d33613f61acc6b12b6ef7b678e525a599b84a/images/4444.png)


Once approved by the admin, users can view the notes; otherwise, they remain inaccessible.
